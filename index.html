MÓDULO I

Estruturas de Dados: Arrays Indexados vs. Arrays Associativos

Um array (vetor) é uma estrutura de dados composta que permite armazenar múltiplas ocorrências de informação sob um único identificador de variável. O erro mais frequente consiste em confundir o tipo do índice com o tipo do conteúdo armazenado.

1. Array Indexado (Posicional)

Cada elemento é acedido através de um índice numérico inteiro (habitualmente começando em 0). O conteúdo armazenado pode ser de qualquer tipo de dados (inteiros, reais, strings ou booleanos). 

// Exemplo em Pseudocódigo:
nomes ← ["Joana", "Carlos", "Ana"]
// nomes[0] contém "Joana"
// nomes[1] contém "Carlos"

2. Array Associativo (Chave-Valor / Mapa)

Em vez de posições numéricas (0, 1, 2), utiliza chaves textuais (Strings) descritivas para indexar cada valor guardado na memória. 

// Exemplo em Pseudocódigo (Q10):
nomes["professora"] ← "Joana"
nomes["aluno"]      ← "Filipe"
// A chave é textual: "professora"

MÓDULO III

Estruturas de Controlo: Ciclos vs. Decisões & Validação

Os seus melhores resultados na prova ocorreram aqui: domina a diferença entre for (repetições conhecidas) e while (repetições condicionadas), bem como a conversão entre ambos (Q12) e a repetição do pedido na validação de inputs (Q14). Fixe apenas estas 3 regras críticas:

Regra 1 • Definição

Ciclo vs. Decisão

Ciclos (for, while) repetem blocos enquanto uma condição for verdadeira (Q06). Decisões (if) apenas escolhem um caminho uma única vez (Prática 5).

Regra 2 • Anatomia do For

Elementos do Ciclo For

Um ciclo for exige inicialização, condição de paragem e incremento. Não exige arrays (Q05) — pode contar simples números inteiros.

Regra 3 • Robustez

Finalidade da Validação

Validar o input do utilizador serve para evitar erros durante a execução (ex: impedir divisões por zero ou quantidades negativas), e não para tornar o programa mais rápido (Q18).

MÓDULO IV

Operadores Relacionais e Álgebra Booleana (Lógicos)

1. Operadores Relacionais vs. Atribuição (Q09)

  • x ← 10 — Atribuição: guarda o valor 10 na variável x.
  • x == 10 — Igualdade: verifica se x é igual a 10 (TRUE/FALSE).
  • x != 10 — Desigualdade: compara se dois valores são diferentes.

2. Tabela de Verdade: AND vs. OR (Q07 e Q20)

Condição A Condição B A AND B (E) A OR B (OU)
TRUE TRUE TRUE TRUE
TRUE FALSE FALSE TRUE
FALSE TRUE FALSE TRUE
FALSE FALSE FALSE FALSE

Aplicação na Q20 (x = 7): (7 > 5) é TRUE e (7 < 10) é TRUE. Logo, TRUE AND TRUE = TRUE.

MÓDULO V

Modularização: Funções vs. Procedimentos

Função (Function) — Devolve Resultado

Subprograma que recebe parâmetros, efetua um processamento e devolve obrigatoriamente um valor ao chamador usando a palavra-chave retornar (Return). 

função CalcularQuadrado(Real Lado): Real
   Real Area
   Area ← Lado * Lado
   retornar Area   // Devolve o valor!
fim_função

Procedimento (Procedure / Void) — Não Devolve Valor

Subprograma que executa uma tarefa (como imprimir um cabeçalho ou menu) e termina sem retornar qualquer resultado. 

procedimento MostrarMenu()
   escrever("1. Quadrado | 2. Círculo")
   // Não possui instrução 'retornar'
fim_procedimento
MÓDULO VI

Leitura de Fluxogramas Flowgorithm & Teste de Mesa

Para dominar a componente prática (que vale 50% da nota final), aplique sistematicamente este protocolo de 3 passos perante qualquer fluxograma:

  1. Identificar Declarações (Retângulos com dupla linha): Conte cada nome de variável separado por vírgula e observe a palavra-chave à esquerda (Integer = inteiro, Real = decimal, String = texto, Boolean = lógico).
  2. Distinguir Formas Geométricas: Losango = Decisão (If); Hexágono = Ciclo (For / While); Paralelogramo Azul = Leitura (Input); Paralelogramo Verde = Escrita (Output).
  3. Construir a Tabela de Rastreio (Teste de Mesa): Simule cada volta do ciclo anotando o valor atual das variáveis e verificando se a condição de impressão é True ou False antes de escrever o resultado final.
MÓDULO VII • RESUMO GERAL

Resumo Completo de Algoritmia: Tudo o Que Precisa Saber

1. O Que É um Algoritmo e Como Funciona o Processamento (IPO)

Um algoritmo é uma sequência finita, ordenada e não ambígua de instruções lógicas para resolver um problema ou executar uma tarefa. Todo algoritmo segue o ciclo Entrada (Input) → Processamento → Saída (Output): recebe dados, aplica cálculos/decisões/repetições sobre variáveis e apresenta o resultado.

2. Variáveis, Tipos Primitivos e Atribuição

Uma variável é um espaço nomeado na memória que guarda um valor que pode mudar durante a execução. Os tipos primitivos definem que tipo de dado cabe nela:

  • Integer (Inteiro): números sem casas decimais (-3, 0, 5, 42).
  • Real (Decimal/Float): números com casas decimais (3.14159, 44.0).
  • String (Texto): cadeias de caracteres entre aspas ("Quadrado").
  • Boolean (Lógico): apenas TRUE ou FALSE.

Atribuição (← ou = em atribuições) coloca um valor dentro da variável, substituindo o valor anterior.

3. Estruturas de Controlo: Sequência, Decisão e Repetição

  • Sequencial: executa uma linha após a outra, sem desvios nem repetições.
  • Decisão (if / else): avalia uma condição lógica e escolhe qual ramo executar uma vez.
  • Repetição / Ciclos (for e while): repetem um bloco de instruções. Use for quando o número de repetições é conhecido/definido (com inicialização, condição de paragem e incremento); use while quando a repetição depende de uma condição que pode variar ao longo da execução.

4. Contadores, Acumuladores, Iteradores e Arrays

Contador (c ← c + 1) conta ocorrências com passo fixo; Acumulador (soma ← soma + v) soma valores variáveis (ex.: total/média); Iterador governa a contagem de um ciclo for.

Arrays agrupam vários valores sob o mesmo nome: indexados usam índices numéricos (guardando qualquer tipo de dado) e associativos usam chaves textuais (mapa["chave"]).

5. Operadores, Validação, Funções e Fluxogramas

Relacionais comparam valores (==, !=, >, <); lógicos combinam condições (AND exige todas verdadeiras; OR exige pelo menos uma; NOT inverte).

Validação de input repete o pedido quando o dado é inválido para evitar erros em execução. Funções devolvem um valor com retornar (Return), enquanto procedimentos apenas executam ações. Em fluxogramas (Flowgorithm) e testes de mesa, siga cada seta e cada condição passo a passo.
