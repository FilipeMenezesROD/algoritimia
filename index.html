O Que Funciona na Prática nos Algoritmos (Passo a Passo)

Quando um algoritmo funciona bem em laboratório ou numa avaliação, é porque segue um método limpo de construção e verificação. Abaixo está o tutorial completo com o que realmente funciona para resolver problemas de algoritmia sem tropeçar:

Passo 1 — Ler o Enunciado e Separar Entradas, Processamento e Saídas

Antes de pôr qualquer bloco ou linha de código, responda: O que entra? (variáveis de Input), O que se calcula/valida? (fórmulas, If, ciclos) e O que sai? (Output ou Return).

Passo 2 — Declarar e Inicializar Antes de Usar

Toda variável precisa de tipo adequado (Integer, Real, String, Boolean). Acumuladores (ex.: soma ← 0) e contadores (ex.: cont ← 0) devem começar com valor inicial antes do ciclo.

Passo 3 — Validar Condições e Evitar Erros de Execução

Se uma quantidade ou divisor não pode ser zero ou negativo, valide antes de calcular (ex.: If Q > 0 ou ciclo While repetindo o pedido enquanto inválido). Isso evita erros e respostas inválidas.

Passo 4 — Fazer o Teste de Mesa (Rastreio) Antes de Concluir

Simule o algoritmo com valores concretos (incluindo casos limite, como o primeiro valor, um valor ignorado por um If e o último passo). Anote cada mudança de variável numa tabela para ter certeza da saída final.

// Exemplo funcional: somar N valores válidos e calcular média
Declarar Inteiro Q, i
Declarar Real valor, soma, media
soma ← 0
Escrever("Quantos valores pretende inserir?")
Ler(Q)
Se (Q > 0) Então
    Para i ← 1 até Q passo 1 Fazer
        Ler(valor)
        soma ← soma + valor
    FimPara
    media ← soma / Q
    Escrever(media)
Senão
    Escrever("Quantidade inválida")
FimSe

Símbolos, Tipos e Vetores

No Flowgorithm, cada "bichinho" (forma geométrica na tela) representa uma operação específica do algoritmo. Saber reconhecer cada forma e cada tipo na declaração resolve a maior parte das questões práticas de prova:

Bloco / Forma no Flow Nome Oficial O Que Faz na Prática
Main / End / Return Terminais & Retorno Marcam o início (Main ou nome da função), o fim (End) ou o valor devolvido por uma função (Return).
Declare (Retângulo duplo) Declaração de Variável / Array Cria variáveis na memória com tipo (Integer, Real, String, Boolean) ou marca a caixa Array com tamanho (ex.: Integer notas[5]).
Assign (Retângulo simples) Atribuição Guarda ou atualiza o valor de uma variável ou posição de array (ex.: Resultado = Valor * Valor ou cont = cont + 1).
Input (Paralelogramo azul) Entrada de Dados Lê um valor digitado pelo utilizador e guarda-o numa variável (ex.: Input Option).
Output (Paralelogramo verde) Saída de Dados Mostra textos entre aspas, valores de variáveis ou resultados de expressões/funções no ecrã.
If (Losango) Decisão Condicional Testa uma condição lógica (True ou False) e segue apenas um dos ramos (não repete em ciclo sozinho).
For / While / Do (Hexágono) Estruturas de Repetição (Ciclos) Repetição controlada: For (início, fim, passo), While (testa antes) e Do (executa e testa no fim).
Call / Breakpoint / Comment Chamada, Depuração e Nota Call executa um subprograma/função; Breakpoint pausa na depuração; Comment documenta sem alterar a execução.

Declarações e Arrays na Prática (O Que Costuma Cair)

Ao declarar uma variável, o tipo define o espaço e as regras: Integer (inteiros), Real (decimais/médias/áreas), String (textos) e Boolean (verdadeiro/falso). Quando declaramos um array com tamanho N, criamos N posições numeradas a partir de 0 até N - 1 (ex.: v[0], v[1]...). Já num array associativo, o acesso é feito por chave textual (ex.: nomes["professora"] ← "Joana"), enquanto o conteúdo de um array indexado pode ser de qualquer tipo.

MÓDULO I

Estruturas de Dados: Arrays Indexados vs. Arrays Associativos

Um array (vetor) é uma estrutura de dados composta que permite armazenar múltiplas ocorrências de informação sob um único identificador de variável. O erro mais frequente consiste em confundir o tipo do índice com o tipo do conteúdo armazenado.

1. Array Indexado (Posicional)

Cada elemento é acedido através de um índice numérico inteiro (habitualmente começando em 0). O conteúdo armazenado pode ser de qualquer tipo de dados (inteiros, reais, strings ou booleanos). 

// Exemplo em Pseudocódigo:
nomes ← ["Joana", "Carlos", "Ana"]
// nomes[0] contém "Joana"
// nomes[1] contém "Carlos"

2. Array Associativo (Chave-Valor / Mapa)

Em vez de posições numéricas (0, 1, 2), utiliza chaves textuais (Strings) descritivas para indexar cada valor guardado na memória. 

// Exemplo em Pseudocódigo (Q10):
nomes["professora"] ← "Joana"
nomes["aluno"]      ← "Filipe"
// A chave é textual: "professora"
MÓDULO II

Variáveis Especiais: Contadores, Acumuladores e Iteradores

Papel da Variável Definição Académica Sintaxe Canónica Armadilha a Evitar
Contador Regista o número de ocorrências de um evento somando/subtraindo uma constante fixa. cont ← cont + 1 cont * 2 não é contador (é progressão geométrica).
Acumulador Totaliza valores variáveis lidos ou calculados ao longo das iterações de um ciclo. soma ← soma + valor Deve ser sempre inicializado a 0 antes do ciclo.
Iterador Variável de controlo que governa a progressão e paragem de um ciclo for. Para i ← 1 até 10 Não deve ser alterado manualmente dentro do ciclo for.
MÓDULO III

Operadores Relacionais, Álgebra Booleana & Funções

1. Operadores e Retorno de Funções

  • x ← 10 — Atribuição | x == 10 — Igualdade | x != 10 — Diferente de.
  • Função vs. Procedimento: Função devolve resultado usando retornar (Return); Procedimento executa ações sem devolver valor.

2. Tabela de Verdade: AND vs. OR

Condição A Condição B A AND B (E) A OR B (OU)
TRUE TRUE TRUE TRUE
TRUE FALSE FALSE TRUE
FALSE TRUE FALSE TRUE
FALSE FALSE FALSE FALSE

Símbolos, Tipos e Vetores

Todos os blocos ("bichinhos") do Flowgorithm, como funcionam as declarações e como diferenciar arrays indexados e associativos:

Bloco / Forma no Flow Nome Oficial O Que Faz na Prática
Main / End / Return Terminais & Retorno Início (Main ou função), fim (End) e retorno de valor de função (Return).
Declare (Retângulo duplo) Declaração de Variável / Array Cria variáveis com tipo (Integer, Real, String, Boolean) ou arrays com tamanho (ex.: Integer notas[5]).
Assign (Retângulo simples) Atribuição Guarda ou atualiza o valor de uma variável ou posição de array (ex.: Resultado = Valor * Valor).
Input (Paralelogramo azul) Entrada de Dados Lê um valor digitado pelo utilizador e guarda numa variável (ex.: Input Option).
Output (Paralelogramo verde) Saída de Dados Exibe textos, variáveis ou resultados de expressões/funções no ecrã.
If (Losango) Decisão Condicional Testa uma condição (True ou False) e segue um dos ramos (não é ciclo).
For / While / Do (Hexágono) Estruturas de Repetição (Ciclos) For (contagem/passo), While (testa antes) e Do (testa no fim).
Call / Breakpoint / Comment Chamada, Depuração e Nota Call chama subprograma/função; Breakpoint pausa na depuração; Comment adiciona comentário.
