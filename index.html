TUTORIAL LOGARITMOS

Tutorial Completo de Logaritmos: Como Fazer & O Que Funciona

1. A Regra de Ouro (Definição que Resolve 80% dos Exercícios)

Um logaritmo responde sempre à pergunta: “A que expoente tenho de elevar a base $a$ para obter o logaritmando $b$?”

loga(b) = x <====> ax = b (com a > 0, a ≠ 1 e b > 0)

Exemplos diretos:
- log2(8) = 3 porque 23 = 8.
- log10(100) = 2 porque 102 = 100.
- log5(1) = 0 porque qualquer base elevada a 0 dá 1.
- log7(7) = 1 porque 71 = 7.

2. Propriedades que Funcionam Sempre

  • Produto vira Soma: loga(X · Y) = loga(X) + loga(Y)
  • Quociente vira Subtração: loga(X / Y) = loga(X) − loga(Y)
  • Potência “tomba” para a frente: loga(Xk) = k · loga(X)
  • Mudança de Base: loga(b) = logc(b) / logc(a) (ótimo na calculadora usando log ou ln).

3. Logaritmos na Algoritmia (Busca Binária / Passos)

Em algoritmia, log2(n) indica quantas vezes conseguimos dividir um problema por 2 até chegar a 1 elemento (ex.: busca binária em 16 itens).

n = 16 → 24 = 16 → log2(16) = 4 passos
n = 32 → 25 = 32 → log2(32) = 5 passos
n = 64 → 26 = 64 → log2(64) = 6 passos

Dica de prova: nunca existe logaritmo de número negativo ou de zero (b <= 0 é inválido) e a base nunca pode ser 1 ou negativa.

FLOW & ARRAYS

Todos os "Bichinhos" (Símbolos) do Flowgorithm, Declaração e Arrays

No Flowgorithm, cada forma geométrica ("bichinho") tem uma função exata. Saber reconhecer o formato e a cor evita errar perguntas sobre ciclos, decisões, leitura, escrita e declaração de variáveis:

“Bichinho” / Forma Nome no Flowgorithm O Que Faz na Prática
Cápsula / Oval (Main / End) Terminal / Função Marca o início (Main ou nome da função) e o fim (End) ou retorno (Return).
Retângulo com Bordas Duplas Declare (Declaração) Cria a variável e define o tipo (Integer, Real, String, Boolean). Pode marcar Array e indicar o tamanho!
Retângulo Simples Assign (Atribuição) Guarda ou atualiza um valor na variável: ex. soma = soma + v ou cont = cont + 1.
Paralelogramo Azul (Input) Input (Entrada) Lê um valor digitado pelo utilizador e guarda dentro da variável indicada.
Paralelogramo Verde (Output) Output (Saída) Mostra texto entre aspas ("Olá") e/ou valores de variáveis/expressões no ecrã.
Losango (If) If (Decisão) Testa uma condição (True ou False) e escolhe um caminho. Não é ciclo!
Hexágono (For / While / Do) Ciclo de Repetição Repete um bloco: For (contagem definida), While (testa antes) ou Do (executa e testa no fim).
Retângulo com Linhas Laterais (Call) Call (Chamada) Chama um procedimento ou subprograma auxiliar para executar uma tarefa.

Declaração & Arrays no Flowgorithm e Pseudocódigo

Declaração: reserva espaço na memória com tipo definido (Integer x, Real media, String nome, Boolean ok).
Array: conjunto de posições indexadas sob o mesmo nome (ex.: notas[0], notas[1], notas[2]). Em arrays indexados, o índice é numérico e o conteúdo pode ser de qualquer tipo; em arrays associativos/mapas, a chave é textual.

Como Não Errar Questões de Fluxograma na Prova

1. Contou variáveis? Conte cada nome separado por vírgula nos blocos de declaração.
2. Perguntou “quais ciclos”? Conte apenas os hexágonos (For, While, Do), ignorando losangos (If).
3. Perguntou “qual o tipo primitivo”? Responda Integer, Real, String ou Boolean.

MÓDULO I

Estruturas de Dados: Arrays Indexados vs. Arrays Associativos

Um array (vetor) é uma estrutura de dados composta que permite armazenar múltiplas ocorrências de informação sob um único identificador de variável. O erro mais frequente consiste em confundir o tipo do índice com o tipo do conteúdo armazenado.

1. Array Indexado (Posicional)

Cada elemento é acedido através de um índice numérico inteiro (habitualmente começando em 0). O conteúdo armazenado pode ser de qualquer tipo de dados (inteiros, reais, strings ou booleanos). 

// Exemplo em Pseudocódigo:
nomes ← ["Joana", "Carlos", "Ana"]
// nomes[0] contém "Joana"
// nomes[1] contém "Carlos"

2. Array Associativo (Chave-Valor / Mapa)

Em vez de posições numéricas (0, 1, 2), utiliza chaves textuais (Strings) descritivas para indexar cada valor guardado na memória. 

// Exemplo em Pseudocódigo (Q10):
nomes["professora"] ← "Joana"
nomes["aluno"]      ← "Filipe"
// A chave é textual: "professora"
MÓDULO II

Variáveis Especiais: Contadores, Acumuladores e Iteradores

Papel da Variável Definição Académica Sintaxe Canónica Armadilha a Evitar
Contador Regista o número de ocorrências de um evento somando/subtraindo uma constante fixa. cont ← cont + 1 cont * 2 não é contador (é progressão geométrica).
Acumulador Totaliza valores variáveis lidos ou calculados ao longo das iterações de um ciclo. soma ← soma + valor Deve ser sempre inicializado a 0 antes do ciclo.
Iterador Variável de controlo que governa a progressão e paragem de um ciclo for. Para i ← 1 até 10 Não deve ser alterado manualmente dentro do ciclo for.
MÓDULO III

Operadores Relacionais, Álgebra Booleana & Funções

1. Operadores e Funções

  • x ← 10 — Atribuição: guarda o valor 10 na variável x.
  • x != 10 — Desigualdade: compara se dois valores são diferentes.
  • Função vs. Procedimento: a função devolve resultado com retornar (Return); o procedimento não devolve valor.

2. Tabela de Verdade: AND vs. OR

Condição A Condição B A AND B A OR B
TRUE TRUE TRUE TRUE
TRUE FALSE FALSE TRUE
FALSE TRUE FALSE TRUE
FALSE FALSE FALSE FALSE
