Fundamentos de Estruturas de Dados e Modularidade

Arrays Indexados vs. Arrays Associativos e Sub-rotinas

Análise formal das estruturas contíguas indexadas, mapas associativos e distinção entre procedimentos e funções.

1. Array Indexado (Vetor de Base Zero)

Acesso Posicional por Índice Inteiro

Em vez de declarar múltiplas variáveis escalares isoladas (item0, item1...), um array indexado agrupa elementos do mesmo tipo sob um identificador único String Array pilotos[5], acedidos por deslocamento a partir do índice 0.

Estrutura pilotos[5] (selecione uma posição): pilotos[1] → "Max Verstappen"
Limite de Limites (Bounds): Para um vetor de dimensão $N = 5$, os índices válidos são $0 \le i \le N-1$, ou seja, de 0 a 4. Aceder a pilotos[5] provoca erro de execução (Index out of bounds).
2. Array Associativo (Mapa Chave → Valor)

Endereçamento Semântico por Chave

Num Array Associativo (também designado por dicionário ou mapa), cada entrada é identificada por uma chave (frequentemente textual), tornando a consulta explícita pelo significado do atributo.

Associação Chave ⇒ Valor:
registo["nome"] "Filipe"
registo["uc"] "00245 - Algoritmia"
registo["perfil"] "Estudante"
Enquadramento no Curso: O Flowgorithm implementa exclusivamente Arrays Indexados ([0], [1], [2]...). Os Arrays Associativos (ou dicionários) são fundamentais na transição para Python, PHP ou JavaScript.
Abstração e Modularização • Subprogramas

Procedimentos vs. Funções: Critério de Retorno

"Um Procedimento executa uma operação sem devolver valor ao chamador (Return Type: None); uma Função computa e devolve sempre um valor tipificado."

PROCEDIMENTO (Return Type: None) Sem valor de retorno

Execução de Tarefa Sem Devolução de Valor

É invocado como instrução autónoma (através de Call). Realiza ações como apresentar menus, escrever cabeçalhos ou formatar saídas, terminando o fluxo sem produzir um valor de retorno para atribuição.

Invocação no Flowgorithm:
Call MostrarMenu()

Não pode ser colocado do lado direito de uma atribuição (x = MostrarMenu() é inválido pois não retorna valor).

FUNÇÃO (Return Type: Integer / Real / String / Boolean) Retorna valor tipificado

Computação com Devolução Explícita (Return)

Recebe parâmetros formais (zero ou mais), executa o processamento interno e encerra através do bloco Return, devolvendo um valor compatível com o tipo declarado ao ponto de chamada.

Invocação no Flowgorithm:
area = AreaCirculo(raio)

O valor devolvido por Return area é atribuído diretamente a area no subprograma chamador.

Selecione uma das simulações acima para observar a transferência de controlo entre o subprograma chamador e o subprograma invocado.
Assinatura de Subprograma: Identificador(lista_opcional_de_parâmetros)

Na definição de um subprograma em Program → Add Function, especifica-se o nome, o tipo de retorno e os parâmetros formais:

1. Parâmetros opcionais:

Se o subprograma não exige dados de entrada, a lista de parâmetros é vazia, ex.: MostrarMenu(). Caso contrário, declaram-se os parâmetros tipados, ex.: AreaCirculo(Real r).

2. Parâmetros formais vs. argumentos reais:

Os identificadores no chamador (raio) não têm de coincidir com o nome do parâmetro formal (r); a correspondência é posicional (por ordem).
