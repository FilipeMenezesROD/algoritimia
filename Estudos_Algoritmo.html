O que são Arrays? (Vetores / Listas em Memória)

Em vez de criares 5 variáveis soltas (nome1, nome2, nome3...), um Array é um armário único com várias gavetas numeradas onde guardas vários valores do mesmo tipo de forma organizada.

Tipo 1 • Array Indexado (Usado no Flowgorithm) Índice Numérico: 0, 1, 2...

Cada gaveta é identificada por um número inteiro chamado Índice. Na programação, a primeira gaveta começa sempre no número 0! Se um array tem tamanho 5, as gavetas vão do índice 0 ao 4.

// Como declarar no Flowgorithm:
Declare String pilotos[5]
pilotos[0] = "Manuela"
pilotos[1] = "Max Verstappen"
Tipo 2 • Array Associativo (Chave → Valor) Etiqueta de Texto

Em vez de números (0, 1, 2), cada gaveta tem uma etiqueta personalizada (Chave / Key) associada a um valor. É muito usado em PHP, JavaScript (Objetos) e Python (Dicionários).

// Exemplo em linguagens web (PHP / JS):
ficha["nome"] = "Gabriel Bortoleto"
ficha["numero"] = 5
ficha["categoria"] = "Fórmula 1"

* Nota técnica: O Flowgorithm trabalha nativamente apenas com Arrays Indexados (índices numéricos a partir de 0).

Como seria se fosse Array Associativo?

piloto["lider"] = "Manuela" → Acedes pelo nome da chave ("lider") em vez do número 0.
