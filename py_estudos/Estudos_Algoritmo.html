Parte I • Estruturas de Dados

Arrays no Flowgorithm: Declaração, Índices e Comparação com Associativos

1. O que é um Array e como funciona no Flowgorithm?

No Flowgorithm, um Array (vetor unidimensional) é uma estrutura de tamanho fixo que armazena vários valores do mesmo tipo (Integer, Real, String ou Boolean) sob um único nome de variável.

Para criar um array no Flowgorithm, usa-se o bloco Declare, ativa-se a caixa Array? e indica-se a Array Size (dimensão). Por exemplo, ao declarar Real Array valores[5], o Flowgorithm cria 5 posições contíguas numeradas de 0 até 4 (valores[0], valores[1], valores[2], valores[3] e valores[4]).

A indexação começa sempre em 0. Se o array tem tamanho N, o último índice válido é N - 1. Tentar aceder a valores[5] num array de tamanho 5 gera erro de limite fora do intervalo (Index out of bounds).

2. Array Indexado vs. Array Associativo

Array Indexado (o único suportado nativamente no Flowgorithm): cada elemento é acedido através de um índice inteiro sequencial (0, 1, 2, ...). É ideal para ciclos For com contador (i = 0 to 4), somatórios, médias, pesquisas lineares e listas de valores.

Array Associativo (também chamado de dicionário, mapa ou objeto chave-valor): em vez de índices numéricos 0, 1, 2, cada valor é associado a uma chave descritiva (por exemplo dados["nome"] ou dados["saudacao"]).

No Flowgorithm não existe tipo nativo de array associativo; quando um exercício (como o Exercício 6 do Caderno 3) menciona um dicionário, no Flowgorithm modela-se com variáveis String separadas (ex.: saudacao e nome) ou passa-se para linguagens como Python, JavaScript ou PHP.

Simulador Interativo: Real Array v[5] (Índices 0 a 4) v[0] = -2.5 | v[1] = 3 | v[2] = 2 | v[3] = 0 | v[4] = 1

Parte II • Modularização no Flowgorithm

Funções vs. Procedimentos, Parâmetros, Return e Call

1. Função (com Return) vs. Procedimento (Return Type: None)

No Flowgorithm, todos os subprogramas criam-se através do Function Manager (menu Program → Function Manager ou botão correspondente). A diferença essencial está no Return Type:

Função tem um Return Type definido (Real, Integer, String ou Boolean) e termina obrigatoriamente num bloco Return que devolve um valor ao ponto onde foi chamada. Exemplo: area = AreaCirculo(raio).

Procedimento tem Return Type: None. Executa tarefas (como mostrar um menu, imprimir linhas ou apresentar resultados) sem devolver nenhum valor. Invoca-se com o bloco Call, por exemplo: Call MostrarMenu().

2. Parâmetros, Argumentos e Âmbito Local

Os parâmetros são as variáveis declaradas na assinatura do subprograma (ex.: AreaCirculo(Real r)). Os argumentos são os valores ou variáveis passados na chamada a partir do Main (ex.: AreaCirculo(raio)).

As variáveis declaradas dentro de uma função ou do Main têm âmbito local ao subprograma onde foram criadas. Por isso, para uma função trabalhar com um dado do Main, deve recebê-lo por parâmetro e devolver o resultado via Return.

Nota importante sobre arrays no Flowgorithm: quando um array é passado como parâmetro para uma função, indica-se o tipo e o nome (ex.: Real Array nums) e o tamanho é tratado conforme a declaração do array chamador.
